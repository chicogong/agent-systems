## 本轮预览：学习入口与白话改稿（2026-10-05）

当前改稿面向学生、老师、AI 工具使用者、感兴趣的人与能力探索者，统一主旨为“学懂 Agent，把方法用起来”；图解与案例先行，源码、架构和编程按需深入。新增[学习与应用导读](learning-and-practice.md)，用同一组虚构材料连接带出处的回答、学习卡片、教学讨论与工作简报。65 个书稿单元已改为更自然的表达：先讲正常任务，解释谁做什么，首次术语加中文说明，来源与完整版本集中在篇末；两组协作 Agent 交换目录审读，并核对各系统至少两个固定源码主张。前言、阅读路线、README、网站和 Markdown 索引同步。

31 张图的文字说明也已补改：按箭头讲正常过程，再集中解释特殊条件；图内旧标签用具体动作说明，便于对照。“任务合同”对应分工清单，“对账”对应查询或核对结果。固定来源、字段与实际执行条件仍保留，本轮补改未重画图。

本轮清单有 **66 个书稿单元、带 PDF 入口的 78 个 HTML 页面与 212 文件的 Markdown 包**；不启用 PDF 时是 77 页。目录/本地链接、16 个系统来源记录和 31 组图的几何预检通过。44 个构建脚本测试、40 个机制示例测试与九个网站单测通过；与 CI 相同的 Playwright 1.63.0 已检查 390 / 1440 px 首次访问、搜索、键盘关闭、分享、学习入口、AI 陪读和图稿放大。MCP 标题与 Hermes 写入条件的两组图已同步修正。首轮白话 PDF 的中文标点换行问题已修复，最终本地候选为 155 页、34 次正文图嵌入；独立实页检查范围见[PDF 审查](reviews/2026-10-05-plain-language-pdf-qa.md)。完整改稿记录见[白话检查](reviews/2026-10-05-plain-language-review.md)，[先期定位记录](reviews/2026-10-05-learning-positioning.md)保留当时结果。

**本轮仍按公开预览发布，不是正式出版。** 正文白话稿已按提交、干净构建、两项 GitHub 检查、部署和线上回读的顺序发布；后续图说明补改也按同样流程更新。各产物的实际版本，请查 [`/version.json`](https://books.aimake.cc/version.json)，不能只根据 Git 推送判断。之后请自愿的不同背景读者复核入门体验。目录短尾留白、真人试读、完整辅助技术阅读、高清封面与印前检查仍要继续；GitHub 的真人试读、分发与印前三个 Issue 保持开放。

7. 阅读站的页面、sitemap、标题锚点与站内文件按每次发布包核对；精确线上版本看 [`/version.json`](https://books.aimake.cc/version.json)，不沿用旧页数。站点所有权与 Search Console 索引/点击数据仍需账号侧验收。GEO 依靠可抓取的原创解释、明确来源和适用边界，不以关键词堆砌或未证实的“AI 收录”作为进度。
8. 已上线的 PDF 是可替换的电子校样，HTML 保持主要阅读入口。下一次 PDF 发布必须重新构建、人工复核、锁定新散列、部署并逐字节验收；正式版需另做权益、无障碍与打印审稿。[学习内容扩展计划](curriculum-expansion.md)优先补正常图解、场景迁移与按需选做的机制实验，不靠堆热门系统名增加页数；[第一册样书询价简报](../book/print-proof-brief.md)已有一册规格和书脊效果图，但实际报价、纸张、印厂模板、可印矢量书脊与封面高清素材均未完成，下单仍等作者确认。

这些工作怎样进入仓库、成书与阅读包，见[写作与校稿方法](editorial-plan.md)；电子定稿、权益、实体样书及正式版本分别按[出版验收单](publication-checklist.md)留证据。

## 发布门槛

| 阶段 | 完成定义 |
| --- | --- |
| 当前预览筹备 | 源稿、图稿及两种导出能构建；未核验范围如实标注。 |
| 首版候选 | 至少 9 个机制主题、至少 4 篇横向对照，现有系统切面二次来源复核；非作者读者能沿机制路线读懂并复述图意。数量门槛不是质量验收。 |
| 公开阅读站 | 只从书稿清单发布审查过的 HTML/SVG；站点链接、标题锚点、私有数据白名单与移动端可读性检查通过，仓库可继续私有。 |
| 公开 PDF 阅读 | 公共 PDF 无失效的私有仓链接；权益、图文、版本说明、下载和索引策略逐项审过，再人工批准上传。 |
| 公开仓库 | 外链、许可、隐私、图源、脚本与历史提交审查通过；明确已知限制后人工决定仓库可见性。 |
| 正式版本 | 候选内容经过完整通读与打印实样检查；人工批准 tag/Release，PDF 与 Markdown ZIP 成为同一个不可变阅读快照。 |

每周构建只产出 **30 天审稿 Artifact**，不会更新研究结论、自动提交生成文件或自动发布 Release。上游版本和外链变化由维护者另行复核；发布后旧剖面继续保留固定版本范围，而不是静默改写为新版事实。
