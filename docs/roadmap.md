## HTTP 学习闭环与教学返修（2026-09-27）

新增[真实本地 HTTP 回执实验](labs/http-receipt.md)：七种场景区分超时、同键重放、内容冲突、读回滞后与迟到登记。HTTP 和读超时真实发生，登记与故障仍为教学夹具，不是生产部署。独立审查推动两次返修：重放再次超时不能伪报冲突；服务登记与读超时的先后需在夹具中明确建立，不能只看通常运行顺序。

上一批的入门最短路线、DSH 准备/结果就绪术语、Hermes 快照例外和界面预算停止说明也已做最小修订。详见[冷读跟进](reviews/2026-09-27-learning-followup.md)、[HTTP 代码审查](reviews/2026-09-27-http-receipt-review.md)与[本轮合稿记录](reviews/2026-09-27-http-learning-pass.md)。

## 发布门槛

| 阶段 | 完成定义 |
| --- | --- |
| 当前预览筹备 | 源稿、图稿及两种导出能构建；未核验范围如实标注。 |
| 首版候选 | 至少 9 个机制主题、至少 4 篇横向对照，现有系统切面二次来源复核；非作者读者能沿机制路线读懂并复述图意。数量门槛不是质量验收。 |
| 公开阅读站 | 只从书稿清单发布审查过的 HTML/SVG；站点链接、标题锚点、私有数据白名单与移动端可读性检查通过，仓库可继续私有。 |
| 公开 PDF 阅读 | 公共 PDF 无失效的私有仓链接；权益、图文、版本说明、下载和索引策略逐项审过，再人工批准上传。 |
| 公开仓库 | 外链、许可、隐私、图源、脚本与历史提交审查通过；明确已知限制后人工决定仓库可见性。 |
| 正式版本 | 候选内容经过完整通读与打印实样检查；人工批准 tag/Release，PDF 与 Markdown ZIP 成为同一个不可变阅读快照。 |

每周构建只产出 **30 天审稿 Artifact**，不会更新研究结论、自动提交生成文件或自动发布 Release。上游版本和外链变化由维护者另行复核；发布后旧剖面继续保留固定版本范围，而不是静默改写为新版事实。
