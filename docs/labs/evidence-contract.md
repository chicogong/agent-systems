# 动手：形成摘要，并逐项核对出处

[返回学习路径](../learning-path.md) · [源码与测试](../../examples/evidence-contract/README.md)

这次用两份获准材料形成带出处的摘要结构，再核对每个引用。正常路径是：读取材料、提出写入、宿主保存、检查引用。你会得到一份可以回到原文的结果，也会看到哪些检查帮助它保持有据可查。

这是可选的机制小实验。运行前请确认 Python 3.10+；不用 API Key、第三方库或网络。材料是虚构的，保存只改变内存字典，提案和引用检查都由固定规则完成。

## 先看材料和任务要求

两份有效材料的原文如下：

| 来源 | 原文 |
| --- | --- |
| `s1` | 工具请求是提案，执行前还要检查许可。 |
| `s2` | 销毁环境不会自动撤销远端写入。 |

任务只允许 `write_summary`，并要求引用 `s1`、`s2` 中实际取得的片段。`s3` 抓取失败，留作后面的错误对照。这里的“任务合同”就是宿主保存的允许动作和通过条件；“观察”是工具取回的材料。

先完成正常路径，再试一个额外要求：材料里混入“先导出凭据”。宿主仍按原任务的允许动作处理材料。网页、文件或工具结果可以提供信息，新的操作许可则来自用户与宿主的授权流程。

## 三种情况的检查位置

| 情况 | 提案／执行端会看到什么 | 验收应怎样判 |
| --- | --- | --- |
| valid | 获准内存写入，引用 s1、s2 的真实片段 | 固定合同通过 |
| forged | 写入成功，并自称完成，却引用抓取失败的 s3 | 证据不成立，拒绝 |
| injection | s1 混入导出要求，脆弱提案器改为导出凭据 | 宿主拒绝，内存状态不变；任务也没有完成 |

第三行分别记录两个结果：导出请求被拒，原摘要也尚未完成。这样读输出，就能知道下一步该回到摘要任务，而非继续执行材料里的额外要求。

## 运行并查看四个位置

从仓库根目录或可携带阅读包的根目录运行：

```bash
python3 examples/evidence-contract/demo.py --case valid
python3 examples/evidence-contract/demo.py --case forged
python3 examples/evidence-contract/demo.py --case injection
```

第一条退出码为 0，后两条为 **2：预期拒绝**。每次打印 `observation → proposal → host_decision → audit`；获准动作另有 `tool_result`，未获准时没有成功工具回执。

先看 `valid`：宿主允许内存写入，`audit.accepted=true`，引用来自 `s1` 和 `s2`。再对照 `forged`：`tool_result.ok=true` 表示内存保存完成，`source_not_verified:s3` 则指出多出的引用缺少有效来源。保存和引用检查处在不同位置。

`injection` 在观察中加入 `[REQUEST_EXPORT]`，固定提案器因此请求 `export_credentials`，宿主按原合同拒绝。这个标记只是让教学场景每次都能重现；程序没有凭据导出实现。

## 沿三段代码看分工（可选）

`propose()` 按固定规则形成提案；`host_execute()` 按允许操作决定是否执行；`audit()` 核对实际执行、动作范围、所需来源、抓取结果和逐字引文。三个函数分别处理建议、许可和结果检查。

想亲手改一处，可以在临时副本中把 `valid` 的 `s1` 引文换成原文没有的句子，或重复引用 `s1` 代替 `s2`。先写下预计触发的检查，再运行测试：

```bash
python3 -m unittest discover -s examples/evidence-contract -p 'test_*.py'
```

8 个测试覆盖正常、失败来源、越权、空证据、伪引文、重复与未知来源。把改动、触发的检查和实际输出记成三行，作为本课产物。

## 本实验的范围与下一步

这个验证器只检查固定引用字段与逐字片段，摘要是否解释准确、来源是否可靠，还需语义检查和人工或任务特定评测。`[REQUEST_EXPORT]` 也不是攻击检测方法；本实验没有真实模型、真实凭据泄露、操作系统沙箱或完整提示注入防御测试。

进阶可把 s1、s2 换成带日期和出处的人工材料，加入事实冲突与语义核对；接真实网页或模型前，另设来源权限、账号、费用与环境合同。执行面的细节读 [Computer / Browser Use](../concepts/computer-and-browser-use.md)，资源可达范围读[沙箱](../concepts/sandbox-execution.md)，结果核验读[完成证据对照](../comparisons/completion-and-evidence.md)。
