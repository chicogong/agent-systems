# 内容权益与运行证据：本轮门禁盘点

[返回当前状态](../roadmap.md) · [来源台账](../../sources/README.md) · [出版验收单](../publication-checklist.md)

这是面向**下一次书稿发布和一册样书询价**的盘点，不是法律意见，也不是整个上游项目的审计。检查范围是本仓当前 Markdown 图片引用、`book/assets/`、图稿目录、字体说明、14 篇系统来源台账，以及本轮两个本地练习的实际输出。

| 对象 | 本轮可核对的事实 | 尚缺的证据/处理 |
| --- | --- | --- |
| 正文示意图 | 正文的 27 次图片引用均指向本仓 `figures/*/diagram.svg`；25 组均有 `.excalidraw`、SVG、PNG、文字版，A4 几何检查通过。没有在 Markdown 中发现直接嵌入上游项目的外部图片。 | 几何检查不能替代逐图事实与印刷可读性；正式版还需核对图中商标、上游图形借鉴或第三方素材。 |
| 选定封面 | `cover-selected.png` 是作者提供的 ChatGPT 生成图，封面脚本使用它的位图插画并重排矢量文字；1024×1536 的原图在 A4 约 131 PPI。 | 留存生成来源与使用条款证据；若向印厂交稿，需要高分辨率原素材或忠实重绘，并按实样检查。仓库的 CC BY 4.0 声明只覆盖有权再许可的部分。 |
| 书脊效果图 | 作者后续提供的 `spine-concept-2026-09-24.png` 已原样归档为设计参考；其宽度、透视背景和位图文字不对应当前实体书脊。 | 该图暂不纳入 CC BY 4.0 再许可范围；须核对生成来源与复用权，拿到印厂模板后以矢量文字重排，不能作为印刷母版。 |
| 字体 | 构建器下载校验固定版本的 Noto Sans SC 与 JetBrains Mono；[字体与许可说明](../../book/README.md)链接其 OFL 来源，本轮本机校验通过。 | 印厂要求轮廓化、嵌入方式和字体子集时，按其模板重检实际 PDF；本记录不重新解释 OFL 条款。 |
| 上游代码与商标 | [14 个系统固定版本的根许可证台账](../../sources/systems.json)通过结构检查；系统正文主要使用链接、文件定位和自己的机制解释。 | 根许可证不等于子目录、依赖、NOTICE、截图、商标或短代码片段逐项授权；正式版要按最终 PDF 对所有第三方片段和标识复核。 |
| 实际运行证据 | 第一练习 3 模式、3 单测；第二练习 4 模式、4 单测在本机通过。两者是无网络、无真实模型的模拟器。 | 不能外推到 Pi、Codex、OpenCode 等系统的端到端行为。Kimi Code 的 mock 测试和 MiMo Code 的纯函数测试也不能替代 CLI/provider/外部写入实测；14 篇仍需择高风险路径补真实环境轨迹。 |

**当前结论：**源稿的本地链接、图稿成组性、来源记录和模拟器测试可以作为预览版的机器门禁；它们不解除封面权益/分辨率、上游第三方素材、实际产品运行与实体样张这四项正式版停止条件。印刷询价可发匿名规格，不先发未经终审的可印文件；网站与 PDF 更新要按各自的人工发布门禁处理。
