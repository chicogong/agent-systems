# 2026-09-27 内容、图稿与排版合稿记录

本轮是持续预览稿的一次本地编辑批次，不是全书终审或正式出版。Markdown 仍为唯一正文，`book/manifest.txt` 控制四种阅读入口的章序；没有复制出另一套 Obsidian 或网站稿件。

## 分工与交叉检查

- 主编辑：书序、源码条件、四组图返修、导出器、网站回归与最终合稿。
- 入门编辑 Agent：学习路线、前言、术语、练习步骤与自测；冷读新实验并复跑，另做移动网页二次检查。
- 实验作者 Agent：新增上下文预算代码与教程；合稿后独立检查 PDF 含图实页。
- 图稿审查 Agent：逐张检查 25 组图及文字版，返修其余四组，核对固定源码定位与实际导出。

这是 Agent 间交叉审查，不冒充真人读者试读。详见[入门记录](2026-09-27-beginner-editor.md)、[图稿记录](2026-09-27-figure-audit.md)与[PDF 实页记录](2026-09-27-pdf-figures.md)。

## 内容改动

新增[上下文预算实验](../labs/context-budget.md)：读者先预测旧权限约束是否进入输入，再运行全量、最近记录、检索三种策略，比较选择记录、实际输入和事后验收。字符预算不是模型 token；规则判读不是 LLM，也不是某个产品的运行模拟。预算过小时拒绝生成，检索命中但无法装入时保留失败轨迹，避免把“搜到了”写成“模型看见了”。

三条入门练习依次解释本地动作、上下文可见性、远端回执丢失。前言与学习路线不要求已有框架经验；术语和自测补充输入、预期输出及失败边界。阅读包同时携带三套示例代码，不只给出网上仓库链接。

MiMo Code 的开关条件对照固定源码重新解释：关闭 checkpoint／memory 写入路径时先绕过重建，不能因为磁盘存在旧文件就画成必定恢复。启用路径中的写入成功、失败／超时与插入失败分别说明。OpenHands 的确认步骤标为条件路径，不暗示每次动作都需人工审批。

## 图稿与源码定位

25 组图实际查看预览和文字说明，返修 8 组：Agent loop、观察评测、MiMo、OpenHands、四种循环、Codex 审批、GPT Researcher、OpenClaw。图源、SVG、PNG 和说明同步维护；原生导出使用固定版本的 Excalidraw 渲染器，没有另画一张替代 SVG。CDN 短暂超时后用同一引擎重试成功。

GPT Researcher 保留非 Granite 的 Hybrid 范围。源码行号曾因网页正文提取而产生误报；改为固定 commit 的 raw 文件逐行核对，确认原有正文定位正确，未将错误的提取行号写回。后续定位同样使用原始文件，不以网页转换后的行数作为 GitHub 锚点。

所有图源生成器重复运行后结果一致；25 组 A4 几何预检通过。预检不证明图意正确或印刷可读。观察图“关联”标签与附近横线仍有 P2 间距优化建议，未确认穿字。Excalidraw MCP 已展示一张图，但交互画布读取受权限限制，未完成交互画布与本地导出的视觉一致性验收。

## 排版、目录与验证

- 修复 GitHub 目录失效的首页标题跳转，并增加本地 Markdown 标题锚点门禁。
- 实际网页检查发现部分中文强调符号原样露出，统一修正；新实验手机窄表改为全宽条目。公开站点构建的 67 页通过静态门禁，四个重点页面在 1280／390px 两种宽度实际截图复核，图片加载正常，没有页面级横向溢出或脚本错误。长命令与模式表仍采用局部滚动，提示可再增强。
- PDF 构建器修复代码链接、嵌套强调、斜体及一级标题标记；目录和书签使用去除 Markdown 语法后的标题，代码标识符保留代码字体。
- 脚本及三套示例共 41 个单测通过；阅读包实际解压后另跑 16 个示例测试。清单为 57 个正文单元，阅读 ZIP 包含 173 个文件。
- 公共链接版候选为 119 页：独立查看全部 29 个含图页，并核对 28 次正文图片嵌入与当前 PNG 的 RGB 像素和尺寸一致。主编辑另看前言、学习路线、目录、新实验、MiMo 正文、术语、结语、作者简介与封底。目录页未见标题语法残留、文字裁切或点线覆盖。

候选 PDF 的精确散列及图页检查范围见独立报告。保存内容提交后重导会更新版本页；须记录新的 PDF 散列，比较页数、正文与图片，再检查版本页，不能将旧报告自动套给任何同名文件。
