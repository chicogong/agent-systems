## 实际运行核对

在仓库根目录使用本机 Python 3.14.6 运行（未另测 Python 3.10）：

- `first-agent-loop/demo.py` 的 `normal / denied / regression`：分别返回 `candidate_ready / blocked / blocked`，配置分别为 `{timeout:5,retries:3}`、`{timeout:30,retries:3}`、`{timeout:5,retries:0}`；3 个单测通过。
- `remote-effect/demo.py` 的 `normal / lost_receipt / no_lookup / unsafe_new_id`：分别返回 `confirmed / confirmed_by_lookup / unknown_stop / duplicate_effect`，模拟副作用数为 `1 / 1 / 1 / 2`；4 个单测通过。
- 在独立临时副本中仅把本地工具的检查改为 `state["timeout"] == 5`：`regression` 的工具检查误报 `ok=true`，最终仍为 `blocked`；3 个测试中只有回归测试失败，原因是缺少 `retry rule changed`。与自测答案一致。未修改仓库示例代码。
- `python3 scripts/check_repo.py` 与 `git diff --check` 通过；本轮添加的相对链接均指向已有文件。

## 剩余缺口与交接

这两条练习能解释确定性控制流，不能测试真实模型选择、网络延迟、迟到请求、幂等键过期或异步发布完成。服务账本只在内存中，操作 ID 也没有跨进程持久化；同一 ID 对应不同请求内容的冲突尚未处理。后续扩展应选一种新的失败条件并提供可控实验，不能仅增加项目名或重复边界声明。当前脚本的模式是教学注入，不是从真实故障日志中归纳出来的路径。

仍需未参与写作的人独立说明：为什么两种 `blocked` 的处理不同，为什么 `unknown_stop` 不是失败，以及 `accepted` 为什么不是任务验收。该真人试读尚未执行。本轮不检查 PDF 分页、网站屏幕效果或图稿像素；这些留给合稿与排版审查。本轮未更新外部课程的维护状态或重审第三方素材许可。

## 新增上下文预算练习二审

独立阅读 `docs/labs/context-budget.md` 与 `examples/context-budget/` 的说明、程序、测试，并复跑默认 `full / recent / retrieve` 及 `recent --budget 248`、`retrieve --budget 91`、`recent --budget 10`。仍使用 Python 3.14.6，没有真实模型或真人冷读。

- 默认三模式的预算／实际字符数为 `1200/248`、`220/212`、`220/217`；可见 ID 顺序与正文表格一致。必要规则与问题为 56 字符。`r1` 的完整渲染记录为 36 字符，默认 `recent` 尝试它时只剩 8。
- `recent --budget 248` 正好装全部 5 条；`retrieve --budget 91` 命中但装不下 `r1`，会继续选中 35 字符的 `r3`，实际总占用 91；10 字符预算生成拒绝 JSON，CLI 退出码为 2。
- `judge_visible()` 只读传入字符串和固定匹配短语；`run()` 取得回答之后，另外传入完整记录调用同一个规则函数用于审计。审计不是独立语义评估，也不回灌原回答。测试在移除全局历史后仍能依据字符串返回结果，预算不足路径则用 mock 确认未调用判读器。
- 修正一处因果描述：检索查询词在 `run()` 内固定，单独改 `QUESTION` 不会改变命中结果；可能导致查不到的是查询词或来源措辞改变，而非程序自动重写问题。
- 把 Python `len(str)` 单位明确为 Unicode 码点，区分屏幕字形、token 与字节；正文与示例 README 补 91 字符时装入 `r3` 的精确路径。代码仅调整 `budget_unit` 标签，未改选择或判读算法。
- 加固测试，钉住正文的精确数值、ID 顺序、拒绝事件、248 边界，以及实际 CLI 退出码。现有 7 测试扩为 9 个，全部通过；相对链接和差异空白检查通过。

结论：可作为“存储 → 字面检索／选择 → 实际输入 → 规则回答 → 另行审计”的入门实验。不能据此推断真实 tokenizer 的预算、模型注意力、语义检索质量或记忆系统效果。改预算只需 CLI 参数；要改来源、问题或搜索词，需阅读代码后改独立副本，精确数字也应重新跑并更新，不能保留旧表格。
