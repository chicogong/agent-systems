# 入门路线冷读与实验复跑记录

[返回当前状态](../roadmap.md) · [学习路线](../learning-path.md)

**范围与方法（2026-09-24）。** 使用 `cursor-agent` 在只读问答模式下，按首次接触本书的读者身份阅读 README、学习路线、Agent loop 与第一条练习，找出会让新手停下的跳跃和歧义。这是**另一 AI 的模拟冷读，不是真人读者测试**；Cursor 没有运行命令。随后由合稿者在本地 Python 3.14.6 下实际运行三种模式和 3 个单测，再核对输出与文案。此记录不证明真实模型 Agent 或 14 个项目的运行行为。

| 冷读发现 | 本轮修订 | 仍需真人验证 |
| --- | --- | --- |
| README 的“按问题进入”与学习路线给出两个不同起点 | README 明确先读 loop、做练习、再读五层职责 | 新读者能否在 15 分钟内找到并完成首条命令 |
| 第一步同时给外部课程、五层和纸笔题，认知负荷过高 | 本地机制和练习优先；外部材料作为选读 | 不会 Python 的读者是否需要无代码版 |
| 概念篇在可运行例子前列出三个源码项目 | 概念篇先链接教学练习，再进入真实项目 | 读者是否知道教学模拟器与真实项目的边界 |
| 概念篇三个控制问题与练习四个代码位置看似矛盾 | 练习解释输入装配被简化、授权与执行被拆开 | 读者能否正确画出分层 |
| 被拒路径仍出现 `proposal write` 和 `tool_result write`，可能误读成已写入 | 增加相邻事件 JSON，强调 `approval.granted=false` 与 `ok=false` | 不看讲解能否从输出辨认拒绝前置 |
| 文案只称两种状态，代码默认还有预算耗尽状态 | 明确三条指定模式不触发 `budget_exhausted` | 读者是否能区分候选完成与用户验收 |

**实际复跑。** `normal` 为 `candidate_ready`，配置 `timeout=5,retries=3`；`denied` 为 `blocked` 且配置未改；`regression` 为 `blocked`，配置 `timeout=5,retries=0`。`python3 -m unittest discover -s examples/first-agent-loop -p 'test_*.py'` 的 3 个测试均通过。新增[远端副作用练习](../labs/remote-effect.md)另由合稿者运行四条模式和 4 个单测通过；它尚未经过 Cursor 或真人冷读。

**导出抽检。** 当前本地公共链接版从 56 篇生成 114 页 A4；PDF 门禁检查 27 次图片使用、702 个来源链接和 9 个嵌入字体，未发现非法内部链接。目视打开封面、第 18 页第一练习起始、第 104–105 页第二练习及封底；第二练习中断行的标点问题已改稿重建。印前拆分得到 1 页封面参考、112 页内文、1 页封底参考，尚无书脊与出血。图稿几何预检的 25 组均通过，但这次没有逐页重看整本或打印实样。Markdown 阅读包含 56 篇、169 个文件，解压后两组示例的 7 个测试均可离线通过。

**发布判断。** 两篇练习可进入**预览书稿**，但不能标记为教学效果已验收。下一步要请未参与写作的人按正文从零运行、口头解释“提案/批准/执行/验收”和“超时/查询/重试”，记录误读点；再根据观察修改文字和图，而不是只看测试通过。
