## 新增的教学能力

[本地 HTTP 练习](../labs/http-receipt.md)将原有内存回执例子接到真实 loopback TCP/HTTP：七种场景、可读轨迹、15 个主路径/错误合同测试及一个慢登记先后测试，共 16 个测试。服务仅绑定 `127.0.0.1` 动态端口，结束释放闸门并等待关闭；无外网、凭据、磁盘写入、模型或真正发布业务。业务登记和故障安排仍是明确的人造夹具。

独立代码审查、初学者冷读与三泳道图分别由三名协作 Agent 负责；主编实现与合稿。图只展开“先登记、读超时、按同 ID 查询找回”，其他故障由正文表格和代码讲解，不把七条路径堆进一张总图。图由同一原生 Excalidraw renderer 导出 SVG/4× PNG，已实际查看；这不证明 MCP 画布字体一致。

## 审查推动的真实修订

- 首轮同 ID 重试的任意非 accepted 结果被写成内容冲突；现仅匹配原 ID 的 HTTP 409 与 `payload_conflict` 才确认冲突，第二次传输超时、不匹配和其他错误保持未知。独立探针复验了整条调用链，不只依赖 helper 测试。
- 首轮 `committed` 事件在 HTTP 超时返回后才等待，不能严格证明图中的登记先于超时。冷读者将处理延迟加到 0.25 秒，复现证据不足；现仅在本地夹具发送后、阻塞读响应前建立对应事件顺序。这个同步不是生产客户端可用的业务证据，宿主判断仍只依据 HTTP。新增测试和同一探针复验了修订。
- 章中显式列出三个确认模式，并说明无参数默认 `normal`，不把六条后续命令误写成“前三条故障”。`host` 与事后观察字段保持分开，两种 404 不被升级为未执行证明。
- 最短学习路线改为只选一个源码项目，额外比较明确可选；DSH 区分准备、派发与结果就绪；Hermes 给 live/seeded/detached 路径加中文解释而保留例外；Computer／Browser 图后说明预算耗尽等未完成停止；路线页裸强调标记修复。
- 同一 manifest 增为 65 单元，图为 30 组；HTTP 代码、测试与 README 加入 Markdown 包和两个 CI 工作流。网页文字版抽取继续排除构建/校准操作，不重复插图。
