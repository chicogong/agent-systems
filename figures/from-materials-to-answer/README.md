# 从零散材料到可靠交付：有出处才写结论

[返回学习与应用](../../docs/learning-and-practice.md) · [图源](scene.excalidraw) · [原尺寸 SVG（手机可放大）](diagram.svg) · [PNG](preview.png)

从左向右看，一次靠谱的资料整理分成三步：左边先把 `D1` 日程、`D2` 场地、`D3` 报名规则编号摆在明面上；中间对照任务要求逐条提取，只写原文能支撑的结论，并守住“只整理草稿、不擅自外发”的动作边界。

右边特意拆成上下两个框：上方绿色框放有明确出处的结论（时间标 `[D1]`、地点标 `[D2]`、截止要求标 `[D3]`）；下方橙色框把原文没提的“报名链接”与“停车位”单列进待确认清单，提示下一步补查，而不是顺嘴编造“无需报名”或“门口可停车”。

这张入门图把全书反复用到的工作习惯浓缩在一屏里：给清楚材料、按边界做事、交出可核对的依据，并诚实标出未知项。
