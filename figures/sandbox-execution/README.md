# 沙箱执行边界：隔离不是撤销

[机制正文](../../docs/concepts/sandbox-execution.md) · [SVG](diagram.svg) · [高清 PNG](preview.png) · [可编辑图源](scene.excalidraw)

这是一张教学机制图，不是某个产品的实现图，也不证明具体运行环境通过安全审计。

## 不看图的说明

1. 宿主先为任务规定资源合同：必要输入、输出位置、时限与最小权限。
2. 工具在所选择的执行环境中工作；文件、网络、进程及资源限制须由具体机制落实，凭据与浏览器登录态另外最小化。
3. 宿主收集退出状态、日志、产物与错误，形成结果账本。收集的是观察，不自动证明结果正确。
4. 在执行环境之外按完成标准检查产物与证据，决定通过、返工或停止。图没有画自动提权重试。
5. 环境结束后，按照合同停止、保留或销毁本地状态。
6. 被允许的出网可能已改变远端业务状态。清理本地环境不会自动撤销远端发布、发送或写入；还需查询与对账。

图中的“执行环境”可能以本地进程策略、容器、用户态应用内核、microVM 或托管环境的某种组合实现，不能据此宣称它们有相同安全边界。暂停、停止、删除保留什么状态，也由具体实现决定。产品层次与官方证据见机制正文及[研究台账](../../docs/field-notes/2026-09-27-sandbox.md)。

## 构建与验收范围

`build.py` 使用仓库共用 `diagram_style.Scene` 生成原生 `.excalidraw`。主路径箭头为实线；外圈虚线表示执行环境边界，橙色虚线箭头表示获准出网时的条件路径。Normal 6 / Code 8，轻手绘 roughness 1，2 px 边框与 3 px 箭头。PNG 与 SVG 必须由 excalidraw-agent 的固定原生渲染器重新导出，不能使用另一套手绘 SVG 代替。

最新图源与导出物的同步情况见[本轮研究交付记录](../../docs/field-notes/2026-09-27-sandbox.md)；每次改图均须重导后打开实际 PNG 复核。MCP 画布会强制使用 Excalifont，未经实际画布检查不承诺与本地字形一致。固定版本与核对元数据不写入画布。
