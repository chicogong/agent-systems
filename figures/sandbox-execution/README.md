# 图的文字版：安排执行环境，再检查结果

[机制正文](../../docs/concepts/sandbox-execution.md) · [SVG](diagram.svg) · [高清 PNG](preview.png) · [可编辑图源](scene.excalidraw)

助手要修复一个 CSV 转换脚本，需要读取样例、写出结果并运行测试。宿主，也就是负责安排执行的运行程序，可以为这次任务准备一块专用工作空间，只提供需要的文件和权限。图中的实线跟着这次工作往下走。

## 从任务准备到取回结果

1. **先列资源清单。** “运行设置”写明这次任务能用什么：输入文件、输出位置、运行时限和最小权限。真正执行前，宿主确认动作在用户允许的范围内。
2. **在选定环境里运行工具。** 文件、网络、进程和资源限制要由具体机制落实。凭据与浏览器登录状态也单独限制，只提供任务需要的部分。
3. **把运行记录收回来。** 包括退出状态、日志、产物和错误。宿主收集这些信息，交给下一步检查。
4. **在环境外检查结果。** 按任务的完成标准核对产物和依据，再决定通过、返工或停止。例如检查输出 CSV 的内容，而不只看程序是否正常退出。图中返工仍按原权限处理，没有自动增加权限的路径。
5. **按原安排结束环境。** 图在清理箭头旁注明“取回产物后”，先保存需要的结果，再选择停止、保留或销毁本地状态。环境外的检查可以随后进行。

## 橙色虚线：任务获得许可后访问网络

如果任务允许发布内容、发送消息或写入远端服务，这些变化发生在图中的“远端业务状态”。结束本地环境以后，仍需到服务端查询结果；返回消息丢失时，先核对原操作再决定是否重试。

外圈虚线标出执行环境，橙色虚线表示获准出网时的条件路径。清理本地工作空间处理的是本地状态，远端发布、发送和写入需要另外处理。

## 阅读具体产品时，再看实现与配置

图中的执行环境可以由本地进程策略、容器、用户态应用内核、microVM（轻量虚拟机）或托管环境组合实现。它们怎样限制访问、暂停或停止后保留哪些状态，都要按具体实现查看。

这是一张教学流程图。具体产品的安全能力需要单独检查和测试，官方资料及产品层次见机制正文与[研究台账](../../docs/field-notes/2026-09-27-sandbox.md)。

## 构建与验收范围

`build.py` 使用仓库共用 `diagram_style.Scene` 生成原生 `.excalidraw`。主路径箭头为实线；外圈虚线表示执行环境边界，橙色虚线箭头表示获准出网时的条件路径。Normal 6 / Code 8，轻手绘 roughness 1，2 px 边框与 3 px 箭头。PNG 与 SVG 必须由 excalidraw-agent 的固定原生渲染器重新导出，不能使用另一套手绘 SVG 代替。

最新图源与导出物的同步情况见[本轮研究交付记录](../../docs/field-notes/2026-09-27-sandbox.md)；每次改图均须重导后打开实际 PNG 复核。MCP 画布会强制使用 Excalifont，未经实际画布检查不承诺与本地字形一致。固定版本与核对元数据不写入画布。
