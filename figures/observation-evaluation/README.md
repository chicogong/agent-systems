# 观察、测试与评测：图的文字版

[返回章节](../../docs/concepts/observation-evaluation.md) · [可编辑图源](scene.excalidraw) · [SVG](diagram.svg) · [PNG](preview.png)

检查助手做得怎么样，可以从一次任务、一组任务和实际使用三个地方看。这张图把它们提供的记录放到一起。

**左上看一次任务。** 日志记下事件和错误；执行轨迹（trace）把同次任务的步骤和调用关联起来；自动检查按事先写好的条件核对结果，图里称为“断言结果”。这三条路各有用途，可以分别收集。

**左下看一组任务。** 用固定任务和相同评分办法检查多个例子，留下逐例结果与汇总。这就是离线评测，图里写作 eval，适合比较版本表现。

**绿色区域看实际使用。** 读者或使用者指出哪里难懂、哪里慢、哪个结果不合用，人工再检查具体例子。一次运行失败后也可以马上复核，按需要安排。

这些记录最后汇到右侧“有范围的结论”：说清楚用了哪个版本、测了哪些样例、什么环境、按什么条件判断，以及还没检查哪些情况。下方红框提醒读者，若要判断整体可用性或安全性，还需要专门的任务和测试。

图主要说明几种记录怎样配合。样例挑选、敏感数据处理、评分器误差和安全测试，接着读正文。
