# 谁决定下一步？

[返回章节](../../docs/concepts/agent-workflow-multiagent.md) · [可编辑图源](scene.excalidraw) · [SVG](diagram.svg) · [PNG](preview.png)

这是一张**概念图**，不是任何项目的源码拓扑。

从上往下读：预设工作流把运行测试、解析日志、生成补丁、校验结果排在程序定义的阶段里，模型可以参与某一步。单 Agent 收到目标与边界后，由模型根据观察选择动作；宿主负责校验和执行，未完成的反馈可进入下一轮。多执行者增加协调者、分工和合并证据的责任；每位执行者内部仍可能是工作流或 Agent。颜色只是辅助，箭头的方向和标签才表达关系。

本图故意省略审批、失败重试、预算、上下文和具体 API。多执行者是否获益，需要对任务分解和合并结果做实测；图不表达“越多越好”。定义依据与 Pi 的固定源码示例见[正文](../../docs/concepts/agent-workflow-multiagent.md)。
