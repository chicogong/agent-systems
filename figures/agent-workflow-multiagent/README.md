# 工作流、Agent 与多执行者的分工

[返回章节](../../docs/concepts/agent-workflow-multiagent.md) · [可编辑图源](scene.excalidraw) · [SVG](diagram.svg) · [PNG](preview.png)

这张图把三种做事方式摆在一起。从上往下读，每一行都是一种安排。

**第一行是预设工作流。** 程序提前排好阶段，例如运行测试、解析日志、生成补丁、检查结果。模型可以参与其中一步，整体顺序由程序安排。

**第二行是单个 Agent。** 收到目标和允许的范围后，模型根据当前结果建议下一步，宿主负责检查和执行。还没做完时，把结果交回模型，继续下一轮。

**第三行是多个执行者合作。** 协调者先分配任务，各执行者分别工作，再把结果交回来。“汇总并核对结果”包括核对内容和出处、处理遗漏和冲突，再检查这些结果能否拼在一起。每位执行者内部，可以用预设工作流，也可以用 Agent 循环；多执行者合作可以采用前两行中的任一种安排。

颜色帮助认出三行；关系由箭头方向和标签说明。分工能否节省时间，要实际检查拆分后的工作和合并成本。

这是一张概念图。审批、失败重试、预算、输入材料和具体接口在其他章节展开；定义依据与 Pi 的固定源码示例见[正文](../../docs/concepts/agent-workflow-multiagent.md)。
