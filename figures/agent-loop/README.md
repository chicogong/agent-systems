# Agent 从任务到结果：概念总览

[返回首页](../../README.md) · [图源](scene.excalidraw) · [SVG](diagram.svg) · [PNG](preview.png)

这张草图表达一个教学模型，不对应某一个项目的实际内部拓扑：用户先给出目标、权限和完成标准；Agent 在模型决策、受控工具执行与结果观察之间循环。尚未解决时继续下一步；有候选结果后进入验证，验证通过才交付。

它有意省略模型 API、会话存储、上下文压缩、人工审批和失败对账。这些会在专题图中分别展开，不应从这张图推断 Pi、Codex 或其他项目的具体代码结构。
