# Agent 从任务到结果：概念总览

[返回首页](../../README.md) · [图源](scene.excalidraw) · [SVG／手机放大查看](diagram.svg) · [PNG](preview.png)

先从“用户任务”开始读：用户说清楚要做什么、允许做哪些事，以及怎样算完成。模型看当前材料，建议下一步；程序检查后执行工具，再把读到的内容或执行结果交回模型。

接着看图里的两个返回箭头。还缺材料时，从“观察结果”回到“模型决策”，继续查找或处理。有了候选答案，就进入“验证”，对照用户要求检查；能修正的问题，再返回模型继续改。检查通过后，交付结果和必要的依据。

如果权限不允许、预算用完，或暂时无法继续，就走到“停止并说明”，告诉用户已做了什么、还差什么。这个出口可以在最终验证之前发生。一个工具报错后是否继续，要结合错误类型和任务条件判断。

紫、橙、红虚线分别帮助找到继续处理、修正和停止的路线；具体条件写在节点与箭头旁。

这是概念图，便于认识循环中的分工。模型接口、聊天记录、长历史压缩、人工批准和外部操作查询会在后面的专题展开；各产品的实际代码安排也可能不同。
