# Agent 从任务到结果：概念总览

[返回首页](../../README.md) · [图源](scene.excalidraw) · [SVG／手机放大查看](diagram.svg) · [PNG](preview.png)

这张图表达一个教学模型，不对应某一个项目的实际内部拓扑：用户先给出目标、权限和完成标准；Agent 在模型决策、受控工具执行与结果观察之间循环。观察后若问题尚未解决，就回到模型决策继续下一步；有候选结果后进入验证。验证通过才交付可复现结果；未通过且可修正则返回模型决策再试。不能继续时进入“停止并说明”，报告失败或未完成的范围，不声称成功。橙、紫、红虚线分别表示验证后修正、继续处理观察、不能继续的条件路径；颜色不是判断条件本身。

“停止并说明”可以在进入最终验证前发生，例如权限不允许或预算耗尽。图为保持简洁，把这些退出原因归入一个出口；不表示所有失败都先经过验证，也不表示一条工具错误必然令整个任务停止。图内短标签和较长解释分开，方便在 A4 页面和手机放大阅读。

它有意省略模型 API、会话存储、上下文压缩、人工审批和失败对账。这些会在专题图中分别展开，不应从这张图推断 Pi、Codex 或其他项目的具体代码结构。
