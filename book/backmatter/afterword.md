# 结语：把一项理解带回自己的生活

读到这里，先选一项你已经能解释的东西。也许是资料怎样进入回答，也许是模型和工具怎样接力，或是几个助手怎样分工。用自己的话讲一遍，再放进一个熟悉的任务里试试。

学生可以整理一页知识卡片，老师可以准备一张讨论图，工具使用者可以改善一份任务说明。想继续研究的人，可以沿源码找出一个函数怎样做判断。每次留下成果、来源和一次修改，就有了继续学习的起点。

Agent 的组件和接口还会变化，书稿也会随之更新。理解一项任务的目标、所需资料、执行步骤和检查方法，可以帮助我们使用新工具，也能帮助我们说明旧方法为什么需要调整。

本书保留可编辑图源和正文来源，方便读者一起核对和修订。你发现一个不好懂的句子、一条解释不清的箭头，或一个与源码不符的判断，都可以提出具体建议。

愿这些图和讲解，陪你从好奇走向实践。先做一件小事，把它解释清楚，再选择下一步。
