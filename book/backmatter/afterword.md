# 结语：把一项理解带回自己的生活

合上书后，你可能还记得某张图：资料怎样进入回答，模型和工具怎样接力，或几个助手怎样分工。选其中一个过程，对照自己的任务，看看哪些步骤相同、哪些地方还需要调整。

尝试时，可以保留一份初稿和修改后的版本。回头看两者的差别：补了哪份资料，澄清了哪个要求，为什么调整检查方法。这些记录能让下一次尝试有据可循。想继续研究实现，也可以沿着章内源码链接，查看关键函数怎样处理输入、选择下一步。

Agent 的组件和接口还会变化，书稿也会随之更新。换用新工具时，可以继续从任务的目标、所需资料、执行步骤和检查方法入手，再看新工具在哪些地方改变了做法。

本书保留可编辑图源和正文来源，方便读者一起核对和修订。你发现一个不好懂的句子、一条解释不清的箭头，或一个与源码不符的判断，都可以提出具体建议。

感谢你读到这里。希望书中的某张图，能在你下一次整理资料、准备教学或使用 AI 工具时派上用场。
