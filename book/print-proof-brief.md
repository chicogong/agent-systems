# 第一册实体样书：询价与印前约束

[返回书稿说明](README.md) · [出版验收单](../docs/publication-checklist.md) · [封面素材边界](assets/README.md)

目标是**先印一册用于内容、图字、装订和纸张验收的样书**，不是申请 ISBN 或宣称正式出版。现阶段只准备询价和版式参考，不自动下单、付款或提交收货信息。现有 A4 PDF 可供看版式，但封面插画约 131 PPI，且没有按印厂模板完成出血、CMYK 与书脊；它**不是可直接上机的印刷母版**。

## 先询哪家、询什么

首选询价入口暂定 [FLBOOK 书籍印刷](https://flbook.com.cn/print/48)：其商品页明列 A4、黑白/彩色、70–120g 等内页、无线胶装、从本地 PDF 上传和 **1 本**数量选项。它适合取得一册的实际报价；页面展示的“￥4.9”等热卖起价**不是本书规格报价**。备选 [FLBOOK 无线胶装画册](https://flbook.com.cn/print/23)支持 A4、一册、本地 PDF，但纸张为铜版/哑粉，可能比文字书厚重且贵。两者的实时运费、印前服务和最终单价仍要在具体页数、纸张、地址确定后比较，不能凭首页起价判定“最便宜”。

向客服发这段规格请求，拿到书面回复再决定供应商：

> 需要先做《图解 Agent 系统》A4 竖版样书 1 本，内文页数与文件尺寸随后按锁稿的**内文 PDF** 提供，含大量彩色流程图、代码和中文。请分别报 80g 双胶纸全彩内页 + 250g 哑膜彩色封面、80g 双胶纸黑白内页 + 同封面的含税/运费价，装订先按无线胶装。请说明实际成品尺寸、内页和封面出血、颜色模式、PDF 标准、字体/图像要求、安全边距、是否可单独上传封面/封底/内文、是否代加空白页，并提供**按所选纸张与最终内页页数生成的含书脊尺寸封面模板**。还请说明是否提供印前文件检查、打样、重印条件和发货时效。

彩色版用于验收本书的颜色语义；黑白版只作节省成本的**备选报价**，不能在未验证图例对比度前直接代替彩色样书。需要先确定可收货的中国大陆地址范围，才能比较运费；不要把地址写进仓库。询价可以先发不含个人信息的规格，不要把未审权益的封面源文件或整书可印 PDF 直接交给第三方。

## 书脊如何设计

作者已选定[书脊效果图](assets/spine-concept-2026-09-24.png)作为设计方向：暖白底、深绿主字、细绿分隔线，底部呼应封面的层叠 Agent。它是宽书脊的视觉概念，**未按最终内文、纸张和装订校准实际比例**。正式文件应以矢量文字和图形重排，不能直接把这张带背景阴影的位图贴到书脊上。

版面优先级是 **《图解 Agent 系统》→ 作者名 → 分隔线／图标 → 副标题**。实际宽度较窄时先删副标题和图标，必要时只保留短书名；不要把文字缩到印后难读。完整书名、作者名与字向仍须在印厂的成品样板上确认，不放虚构 ISBN、出版社标志或未经核实的版次。只有在印厂确认可用书脊宽度、折边和安全区后才排字。

全封面展开的逻辑顺序是 **封底｜书脊｜封面**，还要加印厂规定的外侧出血。**书脊宽度不是由 PDF 页数单独决定**：它取决于实际内页张数、所选纸的厚度、装订工艺及印厂加工余量。现有 `prepare_print_proof.py` 只拆出封面、内文、封底参考文件并在内文末尾补空白到四页倍数；它不画书脊。拿到模板后再把最终封面/封底排入同一展开文件，测量文字安全区，按印厂要求输出印刷母版。内容或纸张变更后重新取模板并复核。

## 交付印厂前的停止条件

1. 锁定本轮书稿与实际内文页数，取得书面报价和模板；明确成品是 A4 还是印厂所谓的 16 开近似尺寸。
2. 逐页检查代码、图注、跨页、空白和页码；公共电子校样与印刷内文分开，不把封面/封底当作内文。
3. 解决封面插画的有效 PPI 与复用授权，检查图稿和字体许可；目前这项未通过，不能声称已有正式印刷母版。
4. 按模板制作含书脊和出血的展开封面，分别输出封面与内文 PDF，让印厂做印前预检。
5. 作者确认最终费用、收货方式与下单版本后才购买；收到实体样书后按[出版验收单](../docs/publication-checklist.md)逐项验收。
