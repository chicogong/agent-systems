# 前言：看见回答背后的系统

“帮我修复这个失败的测试。”一个 Agent 给出补丁，测试也变绿了。可是在这段看似顺畅的过程里，谁决定先读哪个文件？模型提出的命令在哪里执行？工具返回的信息怎样进入下一轮？如果执行中断，系统能从哪里恢复？测试通过，又能证明任务完成到什么程度？

这本书从这些问题出发。我们把 Agent 拆成可观察的机制：运行循环、工具与权限、上下文与记忆、状态与恢复，以及多个执行者之间的协作。概念图先说明关系；开源项目的固定版本源码再展示一种具体做法。图旁有文字版，代码旁有定位，方便读者不依赖某一张图或某一句结论独立核对。

本书写给想理解、使用或设计 Agent 系统的读者。你不必先熟悉书中每个项目；能读懂基本的程序流程和代码仓库，会让源码导读更有收获。可以从机制顺读，也可以带着一个工程问题直接查相应章节。

这里没有“最佳 Agent”榜单，也不把某个项目在固定版本上的做法当作所有 Agent 的标准架构。项目会变，图也会修订。除非章节单独给出可复现的环境与轨迹，源码剖面只说明静态阅读所支持的事实，不代表运行可靠性、安全性或实际任务效果已经验证。

希望读完之后，你带走的不仅是一组图，更是一套追问系统行为的方法。
