# 封面素材与校稿边界

`cover-selected.png` 是书稿发起人从封面设计对话下载并提供的第 1 张**单张正面图**，不含书脊。PDF 第 1 页直接使用这张图；封底由 `scripts/build_book.py` 以可缩放文字和矢量形状绘制，延续奶油白、深绿和深墨色，不使用生成图中虚构的 ISBN、条码或错误许可。

原图为 1024 × 1536 像素，SHA-256 为 `533633cde7a1ce7dbcad0d94bded755b0dbbb69ea2e48fedc284628df9895b28`。在 A4 PDF 中保持原始宽高比、居中留边，有效分辨率约 131 PPI，**足够屏幕审稿，但不是 300 PPI 印刷母版**。简单插值放大不会补回原始细节，因此正式印刷前须取得真正高分辨率原图或重绘可编辑母版，并做实样检查。正文架构图独立核对其有效 PPI 和实际字号。

封面是书籍品牌素材，不是架构事实图；不要把它冒充为 `.excalidraw` 导出。其他生成的封面、版权页、目录和封底方案仅在本地审稿区比对，不作为已核实书页：其中有 CC BY-SA、伪 ISBN、虚构页码等过时占位内容。正式发布前仍需完成封面权益和第三方素材复核。
