# 来源与版本规则

系统剖面在动笔前记录：原项目规范仓库 URL、分析 commit 或 tag、核对日期、相关源码文件与官方文档、取得方法、项目维护状态和许可。项目改名或迁移时，保留旧定位和新定位的关系。

每个重要结论标为以下之一：

- **源码事实**：固定版本中可定位到实现。
- **文档声明**：官方公开文档的说法，尚未独立运行验证。
- **运行观察**：记录环境、输入、版本与可复现结果。
- **工程推断**：基于上述证据作出的解释，必须可与事实区分。
- **未知**：公开资料不足，不补写内部实现。

候选名单不是来源台账。只有开始具体剖面时才建立该项目的固定版本记录，避免把不断变化的默认分支误称为已核验版本。
